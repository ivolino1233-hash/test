Phone setup

Set up a phone

Do this once per phone. The phone must be on the same Wi-Fi as this computer.

You are already on the secure link – the live camera will work. Open the app

  1. Print the reference sheet at 100 % (“Actual size”) and glue it to card.
    1 sheet (PDF) 2 sheets (PDF)
  2. Install the certificate so the phone trusts this computer's secure link (needed for the live camera).
    No certificate on the server yet – run scripts/make_cert.sh on the computer, then restart the app.
    Download certificate
    iPhone / iPad
    1. Open this page in Safari and tap Download certificate → Allow.
    2. Settings → Profile Downloaded → Install (enter your passcode).
    3. Settings → General → About → Certificate Trust Settings → switch on Garment Measure Local CA.
    Android
    1. Tap Download certificate.
    2. Settings → Security (or “Security & privacy”) → More → Encryption & credentials → Install a certificate → CA certificate → Install anyway → pick the downloaded file.
    3. The exact menu names differ by brand; search Settings for “CA certificate”.
  3. Open the app on the secure link (scan the code or tap it), then use your browser's “Add to Home Screen”.

Can't install the certificate?

Use the app on the plain link instead. Live camera is not available there, but Take photo opens the phone's own camera and gives the sharpest pictures anyway.

Phone can't open the page?

  • Phone and computer must be on the same Wi-Fi. Guest networks usually block devices from seeing each other.
  • Allow the ports through the computer's firewall (e.g. sudo ufw allow 8443,8080/tcp).
  • Give the computer a fixed address in the router (DHCP reservation) so the link and certificate stay valid.
